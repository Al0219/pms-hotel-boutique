# 00 — Start Here Backend

Para una tarea Backend nueva, leer `../../AGENTS.md` y `../AGENTS.md`; buscar solo su sección en `AlanPlan.md` y su entrada/estado pertinente en `AlanHandoff.md`. Verificar dependencias, contrato aprobado, DoR, owner/reviewers, aceptación y DoD antes de implementar. Revisar código y pruebas afectados.

El router de `../AGENTS.md` indica qué documentos abrir por tema. Buscar contratos y guías QA por ID/módulo en este directorio; una propuesta no equivale a contrato confirmado. Para un fallo localizado, abrir únicamente las fuentes relacionadas con su causa. Registrar avances y evidencia concisos en plan/handoff cuando corresponda.
