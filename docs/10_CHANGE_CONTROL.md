# 10 — Change Control

## Requiere aprobación
- estructura monorepo;
- framework;
- Route Groups;
- arquitectura por capas;
- nuevo módulo;
- cambio Domain Model global;
- contrato API confirmado;
- nuevo permiso;
- cambio Property Scope;
- desviación Figma;
- nueva dependencia estructural;
- cambio DoR/DoD.

## Proceso
1. propuesta;
2. problema;
3. alternativas;
4. impacto;
5. reviewers;
6. DEC/ADR;
7. PR;
8. QA.

## Prohibido
Cambiar una convención silenciosamente y "actualizar docs después".
