# 09 — Git Workflow

## Repositorio
Un solo `.git` en root.

## Main
Integrable.

## Branches
- feature/
- fix/
- refactor/
- docs/
- test/
- chore/

## PR
Un cambio cohesivo.

## Revisión
- owner principal;
- owner afectado si cross-domain;
- shared requiere reviewer adicional.

## Commits
Conventional-style recomendado.

## Conflictos
Resolver semánticamente.
No usar ours/theirs sin revisar.

## No hacer
- commits directamente a main;
- ramas personales permanentes;
- PR de cientos de cambios no relacionados.
