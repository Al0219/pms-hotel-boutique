# 00 — Project Context

## Propósito
Definir qué producto se está construyendo y qué decisiones de alcance ya están cerradas.

## Producto
PMS Hotel Boutique.

## Objetivo
Gestionar operación hotelera completa con crecimiento multi-property.

## Clientes
- Web Pública.
- Web Privada.
- Android.
- Backend/API.

## Web Pública
Permite:
- buscar disponibilidad;
- consultar habitaciones;
- reservar como invitado;
- autenticarse opcionalmente;
- usar Google opcional;
- crear reservas multi-room;
- asignar ocupantes por estancia;
- ingresar datos;
- gestionar garantía/pago;
- confirmar;
- consultar reservas posteriores;
- administrar cuenta;
- ver historial;
- Rewards;
- promociones;
- facturas.

## Multi-property
El sistema no se diseña como single-property permanente.

Cuando un agregado es property-scoped, su acceso debe declarar el scope.
