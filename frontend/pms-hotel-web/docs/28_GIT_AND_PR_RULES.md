# 28 — Git and PR Rules Web

## Branch
Una tarea cohesiva.

## PR
Debe indicar:
- owner;
- modules;
- Figma;
- API changes;
- shared changes;
- tests;
- DoD.

## Cross-owner
Añadir reviewer del dominio.

## Shared
Reviewer adicional.

## No hacer
- PR gigante;
- change architecture + feature;
- dependency upgrade + feature;
- rename masivo innecesario.
