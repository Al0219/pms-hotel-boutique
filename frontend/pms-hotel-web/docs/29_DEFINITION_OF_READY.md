# 29 — Definition of Ready

Una tarea Web está READY si tiene:

- ID;
- descripción;
- owner;
- módulo;
- Figma;
- route;
- acceptance criteria;
- data needs;
- DTO real/provisional;
- permissions;
- property scope;
- remote states;
- dependencies;
- shared components;
- tests;
- reviewer cross-domain si aplica.

Si falta información crítica:
`BLOCKED / NEEDS CLARIFICATION`.

No implementar suponiendo.
