# 25 — Accessibility

Objetivo:
WCAG 2.2 AA.

## Keyboard
Todas acciones operables.

## Focus
Visible y orden lógico.

## Labels
Campos con label/name accesible.

## Contrast
AA.

## Target Size
>= 24x24 CSS px para targets auditados como base mínima del proyecto.

## Authentication
- password manager;
- autocomplete;
- paste;
- MFA accesible.

## Error forms
No solo color.

## Root clicks
No hacer frame entero clickeable si la acción corresponde a botón específico.
