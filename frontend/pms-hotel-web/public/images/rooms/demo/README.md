# Fotografías ilustrativas de Public 01

Assets generados mediante el skill `imagegen`, modo herramienta integrada `image_gen` (sin API ni CLI). No representan un hotel real. Se conservaron los originales de generación y se exportaron a WebP con Sharp, calidad 82, sin repintar ni alterar el diseño. No se añadió una dependencia al proyecto.

Cada habitación incluye tres archivos: vista principal, segunda perspectiva (`-2`) y detalle de materiales (`-3`). Guardados en `public/images/rooms/demo/`:

- `deluxe-king.webp`, `deluxe-king-2.webp`, `deluxe-king-3.webp`.
- `terrace-suite.webp`, `terrace-suite-2.webp`, `terrace-suite-3.webp`.
- `double-superior.webp`, `double-superior-2.webp`, `double-superior-3.webp`.
- `junior-suite.webp`, `junior-suite-2.webp`, `junior-suite-3.webp`.

## Prompts de variantes

Cada variante utiliza su vista principal como imagen de referencia.

**Segunda perspectiva:** Create a SECOND architectural photograph of this SAME boutique hotel room, photographed from a clearly different angle near the window looking across the room toward the bed(s) and sitting furniture. Preserve the exact number and type of beds, room proportions, cream linens, olive/sage styling, oak furniture and garden/terrace setting from the reference. Wide landscape photorealistic editorial photo, natural daylight, no people, no text or logos. It is an illustrative hotel-demo image.

**Detalle:** Create a THIRD close-up architectural lifestyle photograph from this SAME boutique hotel room, focusing on a bedside corner: linen texture, pillows, oak bedside table, ceramic lamp and warm sunlight, with a little of the bed(s) visible. Keep materials and decor fully consistent with the reference. Wide landscape realistic editorial photograph, no people, no text, no logos. It is an illustrative hotel-demo image.
