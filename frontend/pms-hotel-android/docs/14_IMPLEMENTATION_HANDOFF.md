# Android Implementation Handoff

Before Android implementation, ANDROID-1 must:

1. Confirm language, UI toolkit, minSdk, Gradle, navigation, DI, and networking with the docente.
2. Create the Android project inside `frontend/pms-hotel-android` without a nested Git repository.
3. Establish `Remote/API -> DTO -> Mapper -> Domain -> State/ViewModel -> UI`.
4. Create approved navigation, theme, DTO mocks, and testing baseline.
5. Only then begin approved screens.

The current documentation does not formally approve the Android stack. This Structure Freeze deliberately creates no Android application code.
