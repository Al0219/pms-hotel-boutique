# 00 — Start Here Android

Antes de una tarea:
1. leer globals;
2. leer Android AGENTS;
3. abrir `../../../docs/Backlog_Implementacion_PMS_V1.xlsx`;
4. localizar `IMP-AND-*` autorizada;
5. verificar dependencias/DoR;
6. revisar Figma y contrato cross-app;
7. implementar;
8. tests;
9. DoD;
10. QA/reviewer.

El stack Android se confirma en `IMP-AND-0001`; no asumir tecnología no exigida por el docente antes de esa decisión.
