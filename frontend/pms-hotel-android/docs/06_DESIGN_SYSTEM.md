# 06 — Design System Android

Fuente Figma.

La implementación usa React Native `StyleSheet` y design tokens semánticos. Los tokens se extraen de `238:132 — Implementation Ready — Android V2 + V3`; no se inventa dark mode durante Sprint 0.

Mantener:
- typography;
- colors;
- spacing;
- states;
- accessible targets.

No copiar literalmente componentes Web si Android requiere patrón nativo, pero conservar identidad visual y semántica.

No crear componentes visuales finales o especulativos en la fundación.
