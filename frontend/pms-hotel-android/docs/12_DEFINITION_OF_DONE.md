# 12 — Definition of Done Android

- build/compile PASS;
- tests PASS;
- navigation PASS;
- UI Figma PASS;
- loading/error/offline PASS;
- accessibility PASS;
- no DTO in UI;
- no secrets;
- cross-app semantics PASS.

Para tareas documentales, el equivalente es documentación, ADR y backlog sincronizados, con revisión documental PASS.
